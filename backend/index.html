这个网页用于管理任务和设置。语音聊天在桌面Hiyori窗口中。 打开本机任务台

首次使用与服务配置

先配置需要的服务，再在“模型选择”验证并切换。Ollama 可单独使用，无需 DeepSeek 密钥；语音识别和合成需分别配置。

检查云端连接会使用正常 API 用量。ASR 只检查鉴权与会话建立；TTS 合成一句测试文字但不播放声音。检查通过不代表完整语音或任务能力已验收。密钥只发送给本机服务及对应服务商，不写入聊天记忆。

开始语音聊天

  1. 双击桌面或开始菜单里的 聆泊，找到角色窗口。
  2. 鼠标移到角色窗口内，点击 麦克风图标 开启输入；带斜杠表示关闭。
  3. 保持 喇叭图标 取消静音，回复会从当前扬声器或耳机播放。点击聊天气泡查看文字。

长期记忆

也可在聊天中明确说“记住：内容”。记忆保存在本机；使用云端模型时，会随请求发送给该服务。删除影响之后的新请求，历史聊天与已有任务快照仍保留。凭据继续使用本机加密配置。

Skills

SKILL.md 最多 16 KB；scope 可为 chat、report、work、both，省略时默认 both。每次最多选 3 个。支持 scripts、references、assets 下最多 20 个文字资源，每个 64 KB。脚本每次运行须审阅确认；更新后技能自动禁用。聊天使用“使用技能：编号 你的要求”；工作技能在“后台工作”选择，或明确告诉 Hiyori 技能编号。

整理自己的资料

选择文件夹后会列出支持的资料。读取资料只创建本机快照；点击“生成 Word 报告”后，由当前选择的模型整理。选用云端模型时，正文会发送给该服务。原资料不会被修改。

支持 Markdown、TXT、DOCX、文字型 PDF；最多 20 份、合计 20 MB，提取正文合计最多 60000 字符。扫描 PDF 暂不支持；图片、批注和复杂排版不参与整理。

尚未选择资料。
任务安全暂停后，可修改这里的要求，再点击下方“保存新要求”，影响尚未开始的报告阶段。

整理公开网页

粘贴指定网页链接，后台读取正文并由当前模型生成带来源的 Word 报告。选用云端模型时，网页正文会发送给该服务；原始链接、读取时间及正文快照保存在本机。

任务提交后，在下方“报告任务”查询、暂停、修改要求或取消。

首版只读指定链接，不自动搜索或跟随正文链接，不登录、不点击。仅支持公开 HTML 和纯文本页面；需要登录、验证或 JavaScript 的页面暂不支持，正文可能不完整，请复核快照。单页最多 2 MB、30000 字符，全部资料及编号合计最多 60000 字符。暂停会等待当前页面读取结束或超时。

后台工作

文件、Word、Excel、PowerPoint 和独立浏览器使用同一套任务控制。可在这里输入完整要求，也可以直接对 Hiyori 说。新文件默认放在每个任务的产物文件夹；使用原有资料前请先授权具体文件夹。

文件验收条件（可选）

指定目标文件和需要核对的文字。正文检查支持文本和 DOCX，不判断内容语义或排版。留空仅核验执行记录，仍需人工复核。修改任务时，留空保留原条件，填写则替换原条件。



待确认操作
请核对目标、内容及风险。一次确认仅授权下面这一项动作；暂停、修改、取消后旧确认失效。脚本具有当前用户完整系统权限，不能当作沙箱使用。


实际工具执行记录

修改原件前自动备份；删除仅将单个文件移入备份区。暂停和取消不会撤销已经完成的操作。Office 工具支持 DOCX、XLSX、PPTX；复杂 Excel 扩展、旧格式、宏及任意 WPS 界面操作不承诺保真或成功。独立浏览器需要本机 Edge；登录、验证码和付款由你处理。
