聆泊 · 数据使用说明

聊天、角色配置、明确保存的记忆、Skills 和任务记录存放在当前用户的本机数据目录。

使用 DeepSeek 时，当前对话与任务所需内容发送给该服务。使用云端识别和合成时，音频或待播报文字发送给用户配置的语音服务。

切换 Ollama 只改变语言模型的处理位置，不会使云端语音自动离线。网页访问和经确认的脚本也会按其功能访问外部服务。

在工作台“首次使用与服务配置”新提交的 API 密钥，通过当前 Windows 用户的 DPAPI 加密保存在本机 services.dpapi；界面只显示配置状态，不回显密钥。DPAPI 不防止同一 Windows 用户下的其他程序读取。测试包不包含密钥。

环境变量和本人原有语音配置继续兼容；旧 .env 及配置文件可能仍为明文，不会自动迁移或删除。请勿随代码或压缩包分发这些文件。界面明确清除某项密钥后，该项不会再回退使用旧配置。当前桌面构建关闭产品使用统计和在线自动更新。

新诊断日志默认只记录状态、耗时与计数，不保存聊天和工具正文；后台模型通过本机网关调用，工作进程不继承云端 API 密钥。新日志会按大小轮转，并清理过期或超量的非活动诊断文件。已有历史日志保留。

任务记录、执行所需的本地数据库及产物仍可能包含正文，它们不属于自动清理的诊断日志。经确认的 Skill 脚本具有当前用户的系统权限，这些措施不构成系统沙箱。
