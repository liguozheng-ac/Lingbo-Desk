# 0.3.8：窗口通信与安装包收口

日期：2026-11-19。本轮目标是普通启动、聊天窗口及配置保留检查，并把近期已验证的本机补丁合入同一安装包。没有新增业务能力或重新验收真人语音。

## 确定的改动

`desktop/apps/stage-tamagotchi/src/main/services/electron/window.ts::createWindowService` 原先在边界跟踪启动后，每个可见窗口约每秒 60 次发送位置和尺寸，包括完全没有变化的情况。现保存上次已发送的矩形，只有 x、y、width 或 height 改变时才发出更新；渲染页重新注册跟踪时清空缓存，补发初始快照。隐藏和关闭仍由既有循环管理，不改变窗口样式、鼠标穿透策略、角色帧率或麦克风设置。

这减少的是重复 IPC 和渲染线程事件处理，不是已经测得的输入延迟改善率，也未据此宣布历史卡顿、空白窗口或崩溃根因已修复。

整包纳入近期源码中的连续语音 VAD/ASR 修复、默认 Vivi 女声、本地模式登录请求抑制，以及 Word 固定列宽与跨币种报告约束。相关事实边界分别见 [连续语音修复](voice-continuity-repair.md)、[默认女声](default-female-voice.md)、[本机配置恢复](daily-client-config-recovery.md)和[报告质量复测](report-quality-repair.md)。云服务密钥仍属于用户本机加密配置，不写入分发包。

本轮不重构聊天窗口，不把自动化键入当作真人输入法性能测试，不新增长期稳定性、回声或实时语音结论。安装包为本机未签名构建，尚未验证全新 Windows 机器；安装包仅保留在本机，未作为 GitHub Release 分发。源码及本记录随 0.3.8 更新提交。详细过程、备份及含本机路径的核对文件仅存放在被忽略的 `artifacts/release-0.3.8`。
