## 改动及边界

- `backend/documents.py::export / flush_table`：关闭表格自动列宽，按正文可用宽度分配明确的网格与单元格宽度；表头重复、短行不跨页拆分，统一单元格字号与间距。完整哈希组成的数据行移到表格外；其他长字符串仍可能位于表格内，需要实际渲染验收。保留编号中的连字符，处理单元格粗体标记，将默认模板中的旧 Courier 引用改为 Courier New。
- `backend/work-finalize.mjs::REPORT_FACT_RULES / runVerifiedWork`：向执行模型注入数字、币种、单位、来源和产物回读规则。缺少带来源、日期、换算方向的汇率时不得跨币种比较金额；付款比例高不等于实际付款金额大；未知税率及交易条件应列为待确认。
- `backend/test/document-layout.test.mjs`：用实际 Python 导出器检查 DOCX 网格、单元格、表头、哈希和文字保留；在模拟模型边界检查提示确实传入且工具权限未扩大。

跨币种规则属于提示约束及模型回读，不是确定性的金额计算器或语义校验器。工具执行回执、文件存在、来源哈希均不能单独证明商业结论正确。未增加新的文件访问权限。
