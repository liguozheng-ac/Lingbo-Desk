## 如何理解任务验证

`pnpm run verify:task` 启动真实后端、Agent 工作进程和文件执行模块。
模型响应由本机确定性测试提供，实际执行创建文件与完成检查，没有调用云服务，也没有使用个人凭据。

这项检查证明整理后的执行链能独立运行，不用于证明真实模型的任务成功率。

## 本机原生依赖说明

引擎依赖 `better-sqlite3`。本机尝试下载预编译包时遇到网络重置，后备源码编译没有找到完整 Visual Studio 环境。
本轮运行验证复用了已有的同版本、同 Node ABI 本机预编译缓存，并通过内存数据库查询和实际 Agent 任务检查。

该二进制位于已忽略的安装依赖目录，未纳入源码提交。新机器需要正常取得对应预编译包，或具备本机 C++ 构建环境。

## 构建素材说明

桌面构建使用用户已接受条款的本机 Cubism Core。Core、角色模型和构建缓存均不进入 Git。
未导入角色素材时，编译会报告部分预设资源在运行时解析的提示；新使用者需要自行配置素材。
