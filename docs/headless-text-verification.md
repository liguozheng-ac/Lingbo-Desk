## 范围与环境

用户反馈隔离桌面版打开聊天、聚焦、中文输入及其他窗口操作均卡顿，且鼠标难以脱离工作台；日常版未报告相同现象。经确认，本轮避开所有角色、工作台和桌面输入操作，只检查后台文字与任务执行链。桌面问题没有因此关闭。

启动当前源码 `backend/server.mjs`，使用随机本机端口、独立资料与任务目录。复用本机已授权的加密 DeepSeek 配置，不复制聊天、记忆、目录授权或原有任务。唯一输入为仓库的两份虚构中日文报价及测试文字；调用真实 DeepSeek，工作进程、工具 broker、文件生成及验收未替换。

原始记录、测试脚本和产物位于本机忽略目录 `artifacts/headless-text-verification/run-dZm20i`。原始配置和日志不公开。

## 实际网关与模型：11 个固定检查

| 检查 | 已取得的证据 |
| --- | --- |
| 多轮文字对话 | 同一测试会话先回答 6+4 为 10，再加 7 为 17。 |
| 提交后安全暂停 | 通过 `/sources/import` 上传两份实际合成文件，提交通用工作后暂停，状态最终为 paused，快照含两份来源。 |
| 自然查询已有任务 | 模型调用 `lingbo_work_control progress`，目标为该会话实际任务。 |
| 暂停修改要求 | 通过自然语言把人工复核清单移到开头；实际版本变为 2，保持 paused，两份产物名称与验收约定保留。 |
| 后台运行时继续聊天 | 恢复任务后，前台文字问答 8+9 返回 17，工作状态独立维护。 |
| 自然语言暂停运行任务 | 真实模型调用 pause，工作进程最终进入 paused，随后通过 resume 继续。 |
| 真实产物与工具回执 | 实际生成 compare.md 与 compare.docx；任务 completed，5 条回执。两个当前版本的文件动作回执参与固定输出验收。 |
| 自然语言取消 | 新测试任务通过模型选择 cancel，后台进入 cancelled；随后 1.5 秒观察未出现新增回执。不能由此推导长期无迟到操作。 |
| 生成中断后新回复 | 收到真实流式正文后中止 HTTP 请求，网关 modelsInFlight 回到 0；新文字请求回答木星。没有调用音频播放器。 |
| 重启读取状态 | 加入一个真实提交后暂停的任务；正常关闭、重新启动网关后，completed、cancelled、paused 的任务按 ID 对照，版本、回执数量和产物清单一致；短观察期间未重放。 |
| 日常暂停任务保留 | 独立核对日常任务仍为 paused、版本 1、两份资料、零回执，检查前后任务文件哈希一致。 |

这些是固定流程中的检查点，不是 11 个独立业务任务，不是成功率、稳定性或并发性能统计。实际生成产物的任务只有一个；另有取消和暂停恢复检查用任务。

## 产物核对

通过安装版配套 Python 提取 DOCX 正文，与 Markdown 分别检查“人工复核清单”位于“日文摘要”之前，两项固定标题存在。两份文件均有 S1-Pn、S2-Pn 引用，所用编号在任务输入快照中存在；快照哈希保持一致。

读取样本内容可见：甲为 100 台、含税单价 200 元、设备金额 20000 元、另计运费 800 元；乙为 120 台、单价 180 元、设备金额 21600 元，税费与运费未确认。产物没有给出乙的确定含税到手总价，并提醒数量不同不能直接比较。该人工式样本审阅不是自动语义正确性证明。

本次没有触发需要确认的覆盖动作，因此具体确认列表为空，不能把这次结果称为新的高风险确认验收。没有检查完整 Word 排版、页眉页脚或所有引用的语义蕴含。

## 旧输出丢弃：另有模拟运行时证据

没有启动 Electron。运行与源码匹配的依赖镜像中的既有测试：

- `packages/core-agent/src/runtime/chat-orchestrator-runtime.test.ts`：69 项通过。关键用例包括取消后 provider 忽略 abort 仍能接纳下一轮、迟到的 `obsolete provider output` 不进入会话，以及取消一个会话不影响另一个会话。
- `packages/stage-layouts/src/composables/use-chat-interruption.test.ts`：7 项通过。检查发送前等待打断回执、保持目标会话归属、打断失败不丢替换消息等。

运行前核对 core-agent 与 stage-layouts 的 163 个源码文件与依赖镜像逐字节一致；stage-ui 的相关依赖源码亦核对一致。两组测试使用模拟 provider 或模拟打断回执，不是实际桌面端端到端验收。真实模型的 HTTP 取消和模拟运行时的迟到输出隔离是两类证据，不能拼成“声音已经及时停下”的结论。

## 发现与未完成项

1. 工作模型的完成说明出现“任务完成后保持暂停”，后台实际状态为 completed；修改后的任务要求也加入了未来暂停的措辞。说明文字不能代替状态机。此处应在后续方案中处理，当前未修复，不宣传为所有自然语言控制均准确。
2. 测试脚本最初误读验收结构为 `verification.passed`；真实结构为 scope/checks。随后按实际结构检查两个输出及正文条件。重启检查最初误把任务列表的文件系统顺序当成稳定顺序，修正为按任务 ID 对照。以上是测试断言错误，不是产品故障；复用了已生成产物，没有为修断言重新生成报告。
3. 隔离桌面窗口的卡顿、鼠标占用与退出原因仍未解决。键入监测见 `chat-input-investigation.md`。
4. 真实中文输入法、ASR、麦克风插话、回声处理、TTS 取消与声音停止不在本轮范围内。

测试结束后正常关闭所有本轮网关与工作进程，保留隔离证据文件，不启动日常程序，不推送 GitHub。
