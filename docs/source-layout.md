# 源码目录

```text
Lingbo-Desk/
├─ backend/              HTTP 网关、任务、工具、记忆、Skills 与后端测试
├─ runtime/              Agent 工作进程的协调与初始化
├─ engine/               任务执行引擎源码和依赖清单
├─ speech/               语音识别、合成适配与音频解码
├─ desktop/
│  ├─ apps/              Electron 桌面应用
│  ├─ packages/          桌面共享模块及本地支持组件
│  ├─ server/            客户端编译所需的共享协议和 API 类型
│  ├─ bridges/           角色端与本机后端的连接
│  └─ launcher/          打包启动器与静态页面服务
├─ scripts/              桌面准备、构建和源码检查
├─ resources/local/      本机导入的 SDK 与素材，不进入 Git
└─ docs/                 架构、配置与验收说明
```

桌面源代码只收录当前应用及其依赖闭包。协议类型所需的服务端代码保留在桌面工作区，不表示产品需要部署云端数据库或账户服务。

`support-*` 目录保存支持组件的随包实现及声明文件。它们用于避免构建依赖不存在的远程包名，第三方许可文件随目录保留。这些目录中的 `dist` 是组件依赖，不是本产品的构建输出。

产品编译输出、安装依赖、运行数据和个人 SDK 均通过 `.gitignore` 排除。
此仓库使用新建的 Git 元数据，不包含迁移、改名和升级操作的历史记录。
