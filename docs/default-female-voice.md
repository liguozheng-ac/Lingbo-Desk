# 默认女声音色

日期：2026-11-17。用户要求日常桌面客户端持续默认使用女声。

现有个人配置 `speech-voice.json` 已指定 `zh_female_vv_uranus_bigtts`，但后台 `credentials()` 只有在 `LINGBO_SPEECH_CONFIG` 显式指定时才读取外部语音文件。没有显式指定时，适配器使用 `engine/src/voice/tts-defaults.js` 的默认值，此前该值仍为云舟男声。仅恢复个人音色文件不能保证无显式配置的启动链路使用女声。

本次将源码及当前安装版对应服务模块的 `DEFAULT_DOUBAO_VOICE_ID` 改为 Vivi 女声 `zh_female_vv_uranus_bigtts`。只修改默认值，不禁止今后用户主动选择其他音色，不改密钥、语速、人设或对话数据。适配器对于未提供或空音色的请求均使用该默认值，语言提示不另选男声。

通过工作台正常退出安装版，确认进程退出后替换单个默认模块，并正常重启。正式安装网关实际调用合成接口，返回 29805 字节音频；使用安装版配套解码器成功解码。重启后原创角色仍显示。本机试听与备份位于忽略目录 `artifacts/default-female-voice-2026-11-17`，不发布个人配置、音频或服务凭据。

该验证是实际短句合成与解码，不是麦克风、多语种音质、自然打断或长期稳定性验收。没有生成新版安装器或自动推送 GitHub。
