## 实现与边界

| 模块 | 实际实现 |
| --- | --- |
| `backend/credentials.mjs` | 未填 DeepSeek 密钥返回空值，不再阻止网关启动；真实请求仍检查服务配置 |
| `backend/service-config.mjs::ServiceConfig` | 加密配置优先于环境/旧语音配置；空输入保留，明确清除用 tombstone 禁止旧值回退；带 revision 和原子替换；加密失败保留旧文件 |
| `backend/windows-secret-store.mjs::windowsCrypt` | Windows PowerShell 调用 CurrentUser DPAPI，固定应用 entropy；明文经管道传递，不出现在命令参数、临时明文文件或日志中 |
| `backend/server.mjs` | 认证后的服务状态/保存/检测 API；写入只允许本机工作台来源；忙时拒绝更新并阻止检查期间提交新模型/语音/工作任务；保存后更新网关路由及脱敏器 |
| `backend/service-probe.mjs::probeSpeech` | ASR 只验证鉴权及任务建立；TTS 合成固定短句，消费但不播放音频；模型检测不改变当前选择 |
| `backend/service-dashboard.mjs` | 密码输入框、状态、明确清除、加密保存、分别检查；不读取或回显已保存密钥 |
| `desktop/launcher/package-bootstrap.mjs` | 缺少所选云模型配置时打开沙箱化工作台窗口；不在入口顶层等待 Electron ready，以免阻塞全部窗口 |
| `backend/audio-decoder.mjs::decodeAudio` | Python 子进程使用过滤后的环境；缺依赖或解码失败返回可行动的错误，不返回原始 stderr/堆栈 |

本机配置文件名为 `.local/services.dpapi`。DPAPI 防护静态文件，不构成当前用户内的进程隔离；配置不会跨 Windows 用户直接解密。旧 `.env`/个人 JSON 没有自动删除或转存。损坏、不可解密的已存配置会保留并提示修复，不静默回退或覆盖。当前界面固定面向 DeepSeek、Ollama、阿里云 ASR 与豆包 TTS；不新增任意地址或插件配置能力。

配置快照只包含 revision、是否配置、来源和存储状态，不含密钥值或部分字符。界面没有“检查通过即任务一定成功”的承诺。服务正在工作时不能改凭据；未对已完成动作做回滚。

## 真实服务测试条件

入口为 `scripts/evaluate-real-services.mjs`；必须显式传 `--run-real --services <services.dpapi>`。测试复制本人提供的加密配置到新的隔离工作目录，主程序不依赖本机私有凭据路径。`backend/test-support/real-service-gateway.mjs` 透明转发真实模型输出，只观察状态、时间和 usage；不生成固定模型答案。评测对模型输出施加每请求 1200 tokens 上限、最多 24 次模型请求，全部测试串行。公开浏览器使用实际 Edge、全新独立 profile、headless 模式，不附着个人会话，不登录或批准高风险动作。

测试资料全为固定合成内容；不使用真人麦克风、不播放声音、不读取或改写个人文档。模型为 `deepseek-flash`，识别设置为 `auto`，合成使用当前默认豆包声音。首轮 Python 误选旧安装版运行时，该运行时缺 PyAV：三个语音场景在解码环节失败，尚未进入 ASR。使用完整便携包的 Python 后，仅重跑三个失败语音场景，全部通过。另单独验证新加的 ASR/TTS 连接检测接口。
