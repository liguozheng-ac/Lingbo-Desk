# 新工作台与桌面角色联合检查

日期：2026-11-13（Asia/Shanghai）。本记录接续 [工作台实施与验证](task-workbench-verification.md)，区分自动检查与真人麦克风验收。

## 测试环境

使用安装版 0.3.5 的实际桌面渲染器、原生模块和启动流程，提取到独立测试目录，连接当前源码后端。网关端口 3867，角色端口 5187。角色使用原创 B，自动发送延迟设置为 700 毫秒；自动检查期间麦克风保持关闭。

测试使用新建角色配置和新会话，没有复制日常聊天历史、模型记忆、Skills 或文件目录授权。仅复用本机已有加密服务配置，调用真实 DeepSeek、TTS 和 ASR。上传资料为仓库中的两份合成中日文报价。没有升级或替换安装程序，没有推送 GitHub。

独立测试启动器通过应用 IPC 调用测试入口，调用的是实际 Pinia Chat Store 的 `submit`，随后仍由桌面对话运行时请求模型、选用工具和播报。任务控制测试明确选择 `lingbo_work_control` 工具引用，任务结果来自真实后端状态，不是模拟工具返回。这属于文字触发的集成测试，不能称为用户已经通过麦克风完成同样操作。

## 本轮自动检查

共创建 3 个真实模型后台任务：第一个正常完成；第二个暂停、修改为版本 2 后恢复完成；第三个按测试要求在早期取消。以下 7 项固定检查通过，不是 7 个独立任务，也不是任务成功率统计。

| 检查 | 实际证据 |
| --- | --- |
| 工作台关联角色会话 | 工作台点击提交后，真实任务 `sessionId` 与测试角色当前会话一致 |
| 对话与工作重叠 | 第一项任务运行区间内，角色回答六加四并实际开始 TTS 播放；以桌面 `playback.started.wall` 与后台任务创建、完成时间比较确认重叠，不仅看任务提交与文字回复 |
| 从角色暂停任务 | 模型经实际 `lingbo_work_control` 使第二项任务进入 `paused`；暂停时尚无成功文件操作回执 |
| 从角色修改要求 | 任务保持暂停，要求更新为版本 2，新增“人工复核清单”及三项核对内容 |
| 真实语音服务回环 | 用真实 TTS 生成合成短语音，再调用 ASR 文件入口；实际识别为“6加4等于几只。回答数字。”，保留算术关键词，但标点和分句有偏差 |
| 从角色恢复并交付新版 | 第二项任务恢复后以版本 2 完成，实际 Word 和 Markdown 均包含新增“人工复核清单”；检查的是实际文件，不是助手口头承诺 |
| 从角色取消任务 | 第三项任务通过实际控制入口变为 `cancelled`，没有把完成或失败状态当作取消成功 |

另行核对三项任务涉及的上传原件哈希全部保持不变。任务查询也取得了后台状态与产物信息；其中“运行中、暂无产物”的回复对应其查询时刻，不要求与稍后刷新的页面完全相同。

本轮没有变更产品源码，因此没有重复用单元测试数量代替这次集成证据。此前 131 项后端测试和 6 组浏览器交互检查的范围见前一份记录。

## 调用链核实

工作台通过 `/status.activeLingboSessionId` 关联已连接的桌面对话，提交时固定会话；该状态由角色 `/bridge-event` 的连接和心跳，以及前台模型请求更新。

`desktop/bridges/renderer-bridge.mjs` 注册两个工作工具，捕获对话会话、轮次和参数指纹，执行时携带会话及请求 ID 调用 `/work/control`。`WorkService.find` 检查任务归属，`control` 验证暂停、改版、恢复和取消的允许状态。工具结果再进入桌面对话的模型循环。

语音草稿和文字输入最终共用 Chat Store；`voice-drafts.ts` 提交时捕获输入的工具引用。工具解析还由 `ai/chat-llm/tool-resolver.ts::resolveLlmTools` 合并已注册的默认工具，不能仅根据输入组件列出的工具名称推断桥接工具不可用。本轮没有修改这条逻辑。

本次文字触发的短回答记录了真实 `synthesis.started`、`synthesis.finished`、`playback.started` 和 `playback.ended`。ASR 检查走真实 `/v1/audio/transcriptions`、音频解码和识别服务，但音源来自合成音频，不是物理麦克风。

## 尚未验收

仍需真人在该测试角色上集中确认：持续监听下的 10、17 多轮回答；播报中自然插话并回答木星；旧播报不重现；无需重新开麦克风；嘴型跟随；用自然语音查询、暂停、修改和恢复新工作台的任务。

用户随后反馈“都正常”，经核对并向用户确认，其操作入口为日常安装版角色。独立测试角色在该轮没有新语音请求，预置任务仍为暂停、版本 1，且麦克风未开启。因此保留日常版使用反馈，不将其记作新工作台的真人联合验收。后续只补测试入口核实及任务联动，避免要求用户重做已完成的日常语音检查。

本轮没有可靠的麦克风端到端延迟、误打断率、回声率、日语转写准确率或长期稳定性统计。合成语音回环也不能代表这些指标。
